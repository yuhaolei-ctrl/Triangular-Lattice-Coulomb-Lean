# The triangular lattice minimizes the planar Coulomb renormalized energy

A Lean 4 formalization, against Mathlib, of Theorem 1.1 of Yuhao Lei, *The triangular lattice
minimizes the two-dimensional Coulomb renormalized energy*: for discs or squares and every cutoff
width `L > 0`, every field `E` with `div E = 2π(∑_{p∈C} δ_p − 1)`, `curl E = 0` and bounded density
satisfies

$$W_U(E) \;\ge\; W_U(E_\Lambda) \;=\; \pi R_\Lambda ,$$

where `W_U` is the renormalized energy of Sandier and Serfaty, `Λ` is the triangular lattice of
covolume one, `E_Λ` its canonical field and `R_Λ` the Robin constant of the triangular torus.

> **Status: work in progress.** The statement is fixed in [`Challenge.lean`](Challenge.lean); the
> proof is being developed and still contains `sorry`. The Comparator check will only pass once the
> development is complete. See [`docs/PLAN.md`](docs/PLAN.md) for the structure and
> [`docs/STATUS.md`](docs/STATUS.md) for progress.

## Layout

- [`Challenge.lean`](Challenge.lean): the definitions and the four compared statements (Mathlib only).
- [`Solution.lean`](Solution.lean): the same statements, proved from the development.
- [`TriangularLattice/`](TriangularLattice): the development. `TriangularLattice/Statement.lean` is a
  verbatim copy of the definitions of `Challenge.lean`, generated by `scripts/sync-statement.py`.
- [`certificate/`](certificate): the reference computations in interval arithmetic.
- [`comparator.json`](comparator.json): the Comparator configuration.
- [`formalization.yaml`](formalization.yaml): Palomar metadata.

## Build

Requires the toolchain in [`lean-toolchain`](lean-toolchain) (Lean v4.35.0-rc3).

```sh
lake exe cache get
lake build
```

## Check the statement against the solution

```sh
./scripts/verify-comparator.sh
```

This runs the `lake comparator` bundled with the toolchain, with the bundled independent kernels,
as Palomar does. It needs `bwrap` (Linux).
